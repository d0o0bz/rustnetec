HTTP 端点

GET  /live                     实时连接快照(轮询 1s)
GET  /query?filter=&limit=     SQLite 只读查询(JSON 行数组)
GET  /stats                     SQLite 聚合统计
GET  /config                    读取当前配置
PUT  /config                    更新配置(双轨制:热更新 + 重启生效)
POST /config/restart-capture    重启捕获(应用重启生效项)
